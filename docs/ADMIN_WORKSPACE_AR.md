# مساحة عمل الإدارة — 18 أكتوبر 2026

## العمل اليومي

تعرض الإدارة ملخصًا قابلًا للضغط للإجمالي والمخفي والموقوف وما لم يراجع، وأقسام الجهات، وقوائم للقسم والحالة والعمل. يحافظ الوضع الافتراضي على إخراج السجلات المحدّثة من المراجعة؛ اختيار «جميع السجلات» أو البحث يعيدها. يعرض اختيار المخفي أو الموقوف جميع سجلات الحالة حتى إن كانت قد روجعت سابقًا. يعرض الجدول الاسم والمعرف والقسم والموقع وحالة النشر وجهة التعاقد، مع إجراءات السجل بجواره.

## صلاحية إعادة الإظهار

يتقدم قرار المالك الجديد على قيد عدم نشر أي جهة خارج الشيتات. تظل الجهات غير المسندة محجوبة افتراضيًا، ويستطيع المدير المعتمد اعتماد تعاقدها وإظهارها صراحة، دون اشتراط تعديل ملف Excel أو نشر كود لكل جهة. لا يُعد تعديل الاسم أو تزوير حقل source_ref اعتمادًا. يحفظ الخادم القرار ووقتَه وصاحبَه داخل Medical. تبقى سلطة الإخفاء والإيقاف والحذف قائمة، ومقار الطبيب تحترم إخفاء مستشفاه. لا ترسل هوية صاحب الاعتماد للأعضاء ولا تعد هذه الخطوة إثباتًا لتغطية مالية.

عند حفظ جهة جديدة دون اعتماد الإظهار، تحفظ كمسودة مخفية. النشر الصريح يحتاج اسم جهة التعاقد ومعرفها؛ خدمات الطوارئ يمكن اعتماد عرضها بوصفها خدمة مساندة، دون تصوير الخط الخاص كجهة حكومية. أضيف خيار «المستشفى نفسها / جهة مستقلة»؛ يحمل المستشفى معرفه كجهة تعاقد مستقلة. قوائم المستشفيات تختار المعرف الثابت وتعرض الاسم والمركز لتقليل الخلط بين الفروع.

## القوائم المشتركة

تتيح + إضافة تخصص أو مركز أو نوع جهة وحفظه مركزيًا في medical_options، بدل الاقتصار على متصفح واحد. القيم ذات المعنى التنظيمي الثابت، مثل الدور وحالة النشر وفئة المستفيد، تبقى محددة كي لا تنشأ حالات لا يفهمها الخادم. لا يحتاج تحديث القوائم نشر كود بعد تفعيل الخدمة.

إضافة مستشفى من + تنشئ مستشفى فعلية باستخدام المركز وفئة المستفيد اللذين اختارهما المدير في النموذج؛ تصبح قابلة للاختيار والربط بمعرفها. اختيار الاعتماد ينشرها، وإلا تحفظ مسودة مخفية للمراجعة. تحفظ باقي بيانات الطبيب في النموذج أثناء الإضافة.

## الحساب والحاسب

يفتح الضغط على اسم المدير حسابه، لا الصفحة الإدارية. تعرض البطاقة الاسم والبريد إن وُجد والدور وحالة الحساب ودخول الجلسة وانتهاءها. البيانات لصاحب الجلسة فقط من قراءة محدودة للحساب؛ لا تنسخ كلمات مرور أو تجزئات ولا تعدل MyNekaba.

عند عرض 1100 بكسل فأكثر، يستخدم التطبيق كامل مساحة العمل مع شريط جانبي، وجدول واسع ورأس ثابت للجدول. يحتفظ الموبايل بالتنقل السفلي والبطاقات؛ الجدول الإداري قابل للتمرير أفقيًا دون توسيع عرض الصفحة.

## التحقق والتفعيل

غطت اختبارات الوحدة حماية المدير، واعتماد الجهة غير المستوردة، واستمرار الاعتماد بعد تعديلها، وإعادة إخفائها، وعدم إرسال بيانات الاعتماد للأعضاء، وحفظ القوائم وعزلها عن الأعضاء، وخصوصية بطاقة المدير. غطى المتصفح حفظ تخصص قبل استخدامه وبقاءه بعد إعادة التحميل، وإظهار جهة محجوبة، وإنشاء مستشفى مستقلة من + وربط الطبيب بها، والتخطيط العريض والشاشة الصغيرة.

تحتاج الاعتمادات والقوائم وبطاقة المدير تحديث Firebase، وقدرته admin-workspace-v1. الواجهة تنبه الإدارة عند غياب الإصدار ولا تدعي حفظ عنصر أو اعتماد لم يؤكده الخادم.

```bash
cd ~/cloudshell_open/Medical && git pull --ff-only && bash scripts/deploy-medical.sh --existing-config
```
