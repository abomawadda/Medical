# معمل التطوير الخاص — رعايتي 4.13.0

19 أكتوبر 2026 — أول تنفيذ لـP0 ومعاينات أولية لـP1، وفق [الخارطة المرحلية](PHASED_PREVIEW_ROADMAP_AR.md) و[الاتفاقية](../APP_AGREEMENT_AR.md).

## مكانه وطريقة مراجعته

يدخل المدير بحسابه المعتمد، ثم **الإدارة ← معمل التطوير**. يعرض المعمل ثلاث عينات مصطنعة: الرئيسية المختصرة N-D01، وبطاقة الجهة N-D02، وصفحة تفاصيلها N-D03. البحث والفروع والتبويبات تعمل في النموذج؛ الاتصال والخريطة والتقييم إجراءات توضيحية لا ترسل شيئًا حقيقيًا. لا تمثل العينات تعاقدًا أو أرقام اتصال أو تقييمات فعلية.

لكل عينة زر «الملاحظات والقرار»: انتظار، أو يحتاج تعديلًا، أو اعتماد التصميم فقط؛ مع ملاحظة اختيارية وإيقاف المعاينة للمدير أو استئنافها. تظهر آخر 20 مراجعة. يُرفض فتح النموذج عند اختلاف إصدار التصميم بين الواجهة والخدمة، حتى تحديث النسخة المتوافقة. على المطوّر رفع `previewRevision` في تعريف الخدمة ووحدة الواجهة مع أي تغيير مؤثر في النموذج. إذا تغير إصدار التصميم، يرجع القرار الظاهر إلى انتظار المراجعة وتظهر علامة بأن الاعتماد السابق يحتاج تجديدًا. القرارات المتعارضة لا تستبدل بعضها دون تحديث، وإعادة القرار المطابق لا تكرر الحفظ.

**اعتماد التصميم لا ينشره للأعضاء.** الجمهور ثابت في الخدمة على الإدارة، والتعميم غير مدعوم من هذه النسخة. تنفيذ التفعيل لميزة أو مرحلة يأتي بعد استكمالها ومراجعتها وقرار المالك الصريح؛ لا يوجد زر تعميم شكلي يوحي بوظيفة غير جاهزة. P1 ليست مكتملة وظيفيًا بمجرد هذه العينات، وP2–P6 ما زالت في الخارطة.

## الفصل والحماية

- جميع واجهات المعمل تتطلب رمز جلسة مدير حيًا والتحقق من حسابه المرجعي في كل طلب. الزائر والعضو مرفوضان؛ تعديل الدور في التخزين أو كتابة الرابط لا يمنح صلاحية.
- أُلغي تشغيل التصميم التجريبي القديم بمعامل `experience=companion`؛ يتحول إلى مسار `#lab` المحمي. لا يُستخدم المعامل كتصريح.
- البيانات التوضيحية ترجع من خدمة الإدارة فقط. الكود والتنسيق العامان ليسا أسرارًا، ولا يحتويان بيانات أعضاء أو مفاتيح وصول. لا تعتمد الحماية على إخفاء JavaScript.
- القرارات في `medical_lab_features` داخل Medical، والتدقيق يسجل المعرف والإصدار والفاعل والتوقيت دون نسخ نص الملاحظة. لا كتابة إلى الدليل أو الأخبار أو التقييمات أو إشعارات الأعضاء أو MyNekaba، ولا صلاحيات مصدر جديدة.
- تصلح الملاحظة للتصميم فقط، بحد 1000 محرف، مع رفض HTML ومحارف التحكم. لا تكتب فيها بيانات أعضاء أو أسرارًا. حد 20 يخص التاريخ داخل سجل الميزة؛ ليس سياسة حذف زمني لسجل التدقيق. يبقى اقتراح الاحتفاظ العام مفتوحًا في الخارطة.
- إعادة تحقق كل 20 ثانية أثناء فتح المعمل وظهور الصفحة، وعند العودة للتبويب. يخفي العودة محتوى المعمل حتى تأكيد الخدمة. فشل الاتصال أو سحب الصلاحية يزيل المعاينة؛ لا نسخة خاصة تعمل دون إنترنت. قد تبقى المعاينة ظاهرة إلى الفحص الدوري التالي إذا تغيرت صلاحيتها في تبويب آخر، ولا يمكن محو صورة سبق التقاطها.
- الخروج من المعمل يلغي مؤقته ومستمعيه ومحتواه. فحص المعمل لا يجدد جلسة المدير؛ النشاط البشري يخضع لمنطق الخمول القائم لعشر دقائق.

## نشر الواجهة وتفعيل الخدمة

الواجهة والخدمة خطوتان منفصلتان. الواجهة تعرض زر المعمل للمدير فقط؛ إذا كانت الخدمة أقدم يظهر تنبيه بتحديث Firebase ولا تعرض نماذج محلية بديلة. لا يحتاج الأعضاء تغيير رابطهم.

من Cloud Shell المصرح به سابقًا، بعد التأكد أن إعداد المشروع هو Medical:

```bash
cd ~/cloudshell_open/Medical
git pull --ff-only
bash scripts/deploy-medical.sh --existing-config
```

يحافظ المساعد على الإعداد المحفوظ ويستهدف `we-medical-dakahlia` وحده. يتحقق بعد النشر من `development-lab-v1` مع القدرات السابقة. يمكن الفحص العام دون دخول حقيقي:

```bash
node scripts/check-live.mjs --rayati --require-development-lab
```

لا يُعلن تفعيل المعمل في الإنتاج حتى تنجح القدرة والفحوص المحمية. وجود 4.13.0 في الواجهة وحده يثبت نشر الواجهة فقط؛ البيئة الحالية لا تملك هوية Google لنشر الخدمة.

## التحقق والرجوع

الاختبارات تشمل رفض الزائر والعضو، والتحقق الحي من المدير وانتهاء جلسته، ورفض تفعيل العضو أو حقول دور مزورة، والتزامن والإعادة وإيقاف المعاينة وحد التاريخ وتجديد الاعتماد، ومعاملات Firestore الفعلية في محاكي محلي ببيانات مصطنعة، وعدم تغير المصدر أو دليل العضو.

تغطي اختبارات المتصفح دخول المعمل من الإدارة، وحفظ القرار وإعادة التحميل، والبحث التوضيحي والفروع، ووقف العينة من تبويب آخر، وفشل الخدمة القديمة أو الشبكة، وعرض 320 و390 و768 و1440 بكسل، ورفض رابط المعاينة القديم للأعضاء. الصور الاختبارية تحتوي بيانات مصطنعة فقط، وتحفظ خارج ملفات النشر العامة.

للرجوع عن عينة: أوقف معاينتها من قرارها. لا يتأثر عضو لأن أي عينة ليست مفعلة له. للرجوع عن إصدار المعمل كله، استعد واجهة وخدمة متوافقتين من Git مع إبقاء سجلات القرار؛ لا حاجة لحذفها أو ترحيل بيانات الدليل. لا تغير قواعد Firestore التي تمنع وصول المتصفح المباشر لكل المجموعات.
