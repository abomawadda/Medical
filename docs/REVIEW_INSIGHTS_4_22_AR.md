# صوت الأعضاء — لوحة المؤشرات الخاصة — 4.22.0

23 أكتوبر 2026. استكمال R01/X10/M01 في [الاتفاقية](../APP_AGREEMENT_AR.md) مع بقاء قرار عدم تعميم الجديد للأعضاء.

## موضعها وما تقدمه

الإدارة ← معمل التطوير ← صوت الأعضاء · قراءة التقييمات ← فتح المعاينة.

لوحة للقراءة من البيانات الفعلية المسموح للإدارة بها: عدد الآراء الحالية المنشورة، ومتوسط تجربة الخدمة وتوزيع النجوم وعدد المشاركات لكل عنصر من عناصر الاستقبال والانتظار والنظافة وتنظيم الخدمة. ليست تشخيصًا أو قياسًا لنتائج العلاج أو إثبات زيارة، ولا وصفًا لطبيب بأنه الأفضل.

الفترة لكل البيانات: كل الفترات أو آخر 30 أو 90 يومًا. البحث والقسم يخصان قائمة الجهات تحت عنوان مستقل؛ اختيار جهة منها يغير ملخصها صراحة، مع زر العودة إلى ملخص كل الجهات. القائمة أبجدية، ولا ترتيب تلقائي حسب النجوم أو ترشيح طبي. قسم الجهة من تصنيف الدليل الحالي، وليس توثيقًا لتصنيفها وقت كتابة التقييم.

يعرض المتوسط والتوزيع وعدد النجمة/النجمتين بعد خمس مشاركات صحيحة على الأقل في المجموعة. لكل عنصر عدد مختلف، ولا يحول العنصر غير المقيم إلى صفر. تبقى المجموعات الأصغر بأعدادها وعبارة «تجارب غير كافية». هذه عتبة عرض تحفظ التحفظ عند قلة العينة؛ ليست ضمانًا للخصوصية الإحصائية أو دليل ثقة طبيًا.

## معنى الفترة والتوحيد

`updated_at` هو وقت آخر كتابة للنسخة، ويحول إلى يوم القاهرة؛ آخر 30 يومًا يعني اليوم و29 يومًا قبله. لا يستعمل وقت اعتماد المدير كتاريخ زيارة، ولا يحسب تعديل العضو زيارة إضافية. نشاط آخر 14 يومًا يعرض أعداد النسخ المنشورة الحالية حسب أيام كتابتها داخل الفترة المختارة، وليس عدد مرات الدخول أو المرضى أو الزيارات.

تقارن جميع الحالات أولًا وتختار أحدث نسخة لكل معرف كاتب مبهم ومعرف جهة قانوني؛ النسخة المعلقة أو المخفية الأحدث تمنع إعادة استعمال المنشورة القديمة. عند تساوي الوقت يستخدم ترتيب المعرّف نفسه المعتمد في أدوات المراجعات الحالية. روابط التكرار المراجعة في الدليل هي وحدها التي توحد أهداف المراجعة، ولا يكفي تشابه الأسماء أو اشتراك فروع في علامة تجارية. لا يسقط اختلاف اسم متشابه هوية طبيب مستقل.

لا تخمن شبكة مستفيدين أو مكان زيارة من أهلية جهة مشتركة، ولا تنسب آراء مجمعة إلى فرع غير مسجل. لا تعرض واجهة التحليل حقولًا حرة عن الأعضاء. المعرفات غير المرتبطة بجهة حالية تعرض باسم عام ومعرف مهشم، دون إظهار قيمة مصدر غير مفهومة قد تحمل نصًا غير ملائم.

## حدود المصدر وجودته

`reviewInsightsRead` يقرأ من Medical فقط: `author_id`, `target_id`, `status`, `rating`, `criteria`, `updated_at`, `revision` ومعرّف الوثيقة. لا ينتقي `author_name` أو `comment` أو الكود أو الهوية أو الموبايل. معرف الكاتب مبهم ويستخدم داخل الخادم فقط؛ لا يعاد في استجابة المؤشرات أو JSON المنزل.

القراءة مرتبة بمعرف الوثيقة ومحدودة إلى 2001. حتى 2000 وثيقة تكون اللقطة كاملة ضمن قاعدة المصدر المقروءة. عند وجود وثيقة إضافية لا تعرض مؤشرات أو جهات أو تقريرًا جزئيًا، لأن اختيار مجموعة عشوائية أو حسب أحدث سجلات قد يحيز المتوسط. لا ادعاء بعدد إجمالي دقيق أكبر من السقف، ويلزم عنده مسار تجميع خلفي أوسع واختبار تكلفة مستقل.

يقبل الوقت الرقمي بالمللي ثانية أو ISO بمنطقة زمنية صريحة فقط؛ الصيغ المحلية الملتبسة لا تُفسر تلقائيًا. التاريخ غير المفهوم أو المستقبلي أو الحالة غير المعروفة يعزل مجموعة العضو/الجهة بدل الرجوع إلى منشور قديم مشكوك فيه. الهوية الناقصة والدرجات خارج 1–5 تستبعد من الحساب، والعنصر غير السليم يستبعد وحده، مع أعداد ملاحظات جودة. عند تعذر المصدر تظهر رسالة فشل، لا أصفارًا. أعداد الجودة مؤشرات مراجعة وقد تكون أكثر من ملاحظة للوثيقة؛ لا تعني عدد زيارات تالفة أو اتهام عضو.

دليل الجهات ولقطة التقييمات يقرآن للملخص، ولا يعد التقرير معاملة تاريخية ذرية لكل بيانات التشغيل. اللقطة مؤرخة، والتحديث بطلب المدير؛ ليست لوحة رصد لحظي.

## الحماية والسلوك

- `GET /v1/admin/lab/review-insights?period=all|30|90` يتحقق حيًا من المدير ومن إيقاف العينة قبل القراءة وبعدها. تغير مراجعة العينة أثناء القراءة يمنع تسليم لقطة بقرار قديم.
- `GET /v1/admin/lab/preview/review_insights?status=1` يعيد سياسة العينة فقط للفحص الدوري كل 20 ثانية وأثناء عودة التبويب؛ لا يسحب سجلات التقييم. لا يجدد جلسة خمول المدير.
- الردود `no-store`؛ لا أسماء أو نصوص أعضاء في هذا العرض، ولا حفظ للتقارير أو البحث أو المرشحات في localStorage أو Firestore. تحفظ مرشحات هذه الصفحة في ذاكرة هوية المدير الحالية وتزال عند الخروج أو إعادة التحميل.
- انقطاع الاتصال أو فشل التحقق أو الإيقاف يزيل عرض المؤشرات؛ الرد المتأخر لا يعيد صفحة غادرها المدير. العضو والزائر مرفوضان خادميًا حتى بتزوير مسار الواجهة أو الدور المحلي.
- لا مسار كتابة هنا. أدوات اعتماد وإخفاء التقييمات القائمة مستمرة بقواعد المراجعات والموافقة المنفصلة على مشاركة نص، ولم تعدل هذه المرحلة قراراتها أو جمهورها.
- JSON المنزل من الأعداد الإجمالية للقطة المعروضة؛ لا قائمة جهات أو بحث أو أسماء أو تعليق أو معرف عضو. يعاد تحقق الصلاحية وسياسة العينة قبل التنزيل؛ يعكس التقرير تاريخ اللقطة ولا يدعي جلب بيانات أحدث عند التنزيل.

أثبت فحص بداية المهمة أن خدمة القراءة المريحة السابقة منشورة. البيئة الحالية بلا هوية Google مخولة؛ نشر Vercel أو Pages لا يثبت تحديث Firebase. من Cloud Shell المخول:

```bash

```

```bash

```

الرجوع بإيقاف عينة صوت الأعضاء من المعمل؛ لا حذف تقييمات أو تعديل مصدر. تبقى الأدوات والواجهات السابقة. لا تغيير لقواعد المصدر أو IAM أو نسب تحمل أو لوائح الشركة.

## الفحوص

اختبارات مصطنعة للتوحيد قبل الترشيح حسب الفترة، وحفظ استقلال الفروع والأسماء المتشابهة، وعزل التاريخ أو الحالة غير السليمين، وعدم تحويل الناقص إلى صفر، وحد العينة، وحد المصدر، ومنع خروج المعرفات والنصوص، وصلاحية المدير أثناء القراءة والإيقاف وترويسات HTTP. محاكي Firestore يختبر إسقاط الحقول الحقيقي وتوحيد الأهداف المعتمدة وبقاء التقييمات والدليل والمصدر كما هي. رحلة المتصفح تختبر الفترة والبحث والقسم المستقلين، واختيار الملخص، وقلة العينة، وتقرير الأعداد، والإيقاف ومقاسات 320–1440. يسجل التسليم النتائج الفعلية بعد انتهاء الفحوص.

تعرض قائمة الجهات حتى ثلاثة أوصاف مكان من دليلها الحالي للمساعدة على تمييز الأسماء المتشابهة والفروع، ويبحث المدير فيها محليًا مع الاسم. هذه أوصاف جهة في الدليل وليست مكان زيارة مستنتجًا للتقييم، ولا تبدل مجموعة حسابه أو تدمج فروعه.

نتيجة التحقق المحلي: **214 اختبار وحدة وحماية ناجحًا**، ورحلة Chromium الكاملة دون أخطاء تشغيل، ومحاكي Firestore ناجح، وبناء الأصول وفحصها ناجحان. شملت الرحلة الفترة والقائمة والملخص المستقلين، وقلة العينة، والتقرير الخالي من أسماء الأعضاء والجهات ونص البحث، وحجب نتائج المصدر المتجاوز للسقف، وإيقاف العينة، ومقاسات 320–1440. لا دخول إنتاج خاص أو تعديل تقييمات أو مصدر من الاختبارات.
