# خيارات الجهاز والخصوصية — 4.23.0

## المكان والنطاق

الإدارة ← معمل التطوير ← تجربة الدليل المترابطة ← خيارات القراءة والعرض ← «أنت تتحكم بما يُحفظ». استكمال R03/D07 في العينة القائمة للمدير فقط. لا تعديل لتجربة الأعضاء أو الدليل أو التقييمات أو MyNekaba. حفظ العرض لا يحتاج قاعدة بيانات أو مجموعة Firestore جديدة.

## ما يعمل

- القراءة تبقى في ذاكرة الجلسة ما لم يضغط المدير صراحة زر حفظ الخيارات على المتصفح. يسبق هذا الزر تحقق خادمي حي من صلاحية المدير ومراجعة العينة، ولا يكتب إذا أوقفت أو اختلف الإصدار أثناء الفحص.
- مفتاح التخزين الوحيد `rayati:admin-preview:reading:v1`؛ يحتوي `version` و`savedAt` وأربعة خيارات `size/compact/contrast/calm` فقط. لا هوية حساب أو اسم أو بيانات عضو أو بحث أو موضع تمرير أو جهة مفضلة أو تعليق أو إحداثيات. مخطط محصور يستبعد أي بيانات إضافية عند الكتابة ويرفضها عند القراءة.
- الحفظ يخص المتصفح على هذا الجهاز، لا الحساب؛ يظهر ذلك قبل الاختيار كي يعرف المدير أثر استخدام متصفح مشترك. لا مزامنة ولا تخزين سحابي. تسجيل الخروج لا يمس هذه الخيارات غير الشخصية، ولا يظهرها للعضو ما لم يصبح مديرًا ويفتح المعاينة. يمكن مسحها من المعاينة أو إعدادات الموقع في المتصفح.
- تستعاد الخيارات بعد تحقق الدخول والمعاينة فقط. تنتهي بعد 90 يومًا من آخر حفظ؛ تغيير القراءة أثناء تفعيل الحفظ يجدد الموعد. الإعداد التالف أو المنتهي أو المؤرخ مستقبلًا يُزال دون قراءة أو عرض أي حقول إضافية؛ فشل المسح لا يُعلن نجاحًا.
- «استعادة العرض العادي» يغير القيم ويُحدّثها إن كان الحفظ مفعّلًا. «مسح خيارات القراءة المحفوظة» يوقف الحفظ ويعيد العرض العادي. لا يستدعي `localStorage.clear` أو مسح Service Worker ولا يحذف الجلسة أو المفضلة. تبقى سياسة تذكر الدخول مستقلة.
- مسح المفتاح من تبويب آخر يوقف الحفظ ويعيد العرض العادي هنا. التخزين الممنوع أو الممتلئ يظهر كتخزين غير مؤكد ويترك الدليل متاحًا بإعدادات الجلسة.
- فحص الأذونات يقرأ `permissions.query(geolocation)` وحالة `Notification.permission` ووضع العرض فقط. لا `getCurrentPosition` ولا `requestPermission` ولا تسجيل دفع. فشل أو غياب API يظهر «تعذر تحديد الحالة/غير مدعوم»؛ إذن الإشعارات لا يعني أن التطبيق يرسلها. التغيير من إعدادات الموقع في المتصفح.
- فتح تبويب متصفح لا ينفي أن التطبيق مثبت؛ لا يفحص التطبيق قائمة برامج الجهاز، ولا ينسب تثبيتًا لمجرد الحفظ. تعرض الحالة «طريقة الفتح الحالية» بدقة.

## الإصدار والحماية

العينة `directory_experience` مراجعتها `p1-directory-20261023-3`؛ المعمل والخادم والصفحة تتحقق من توافقها. اعتماد تصميم سابق يعود للانتظار مع إبقاء تاريخه، وحالة الإيقاف تبقى محفوظة. تتغير هذه العينة فقط؛ `visit_workspace` وبقية المعمل مستمرة بإصداراتها. مرجع الجاهزية `p0-readiness-20261023-3`. التعميم للأعضاء غير مدعوم، وليس هذا اكتمال إعدادات الخصوصية أو الإشعارات لهم.

## التشغيل والرجوع

تحتاج الواجهة 4.23.0 وخدمة بقدرة `development-device-preferences-v1`. أثبت فحص بداية العمل نشر قدرة صوت الأعضاء 4.22؛ البيئة الحالية بلا هوية Google للنشر الخلفي. رفع الواجهة وحده لا ينشر المراجعة الخادمية.

من Cloud Shell المخول:

```bash
cd ~/cloudshell_open/Medical && git pull --ff-only origin main && bash scripts/deploy-medical.sh --existing-config
```

فحص عام للقراءة دون حساب أو سجل عضو:

```bash
NODE_USE_ENV_PROXY=1 node scripts/check-live.mjs --rayati --require-device-preferences --require-review-insights --require-directory-comfort
```

للرجوع: أوقف معاينة الدليل من المعمل؛ لا تفعيل للأعضاء ولا حذف مصدر. إذا اختير إصدار سابق للواجهة والخدمة معًا يتجاهل مفتاح القراءة الجديد. لا يحتاج الرجوع إلى تنظيف بيانات التشغيل. مفتاح الخيارات غير الشخصية يمكن مسحه لاحقًا من المتصفح.

## خطة الفحص

اختبارات مصطنعة لحصر الحقول والمفتاح وعمر 90 يومًا والتاريخ المستقبلي والإصدار والبيانات التالفة ومنع التخزين والامتلاء والفشل الصامت وفحص الأذونات دون طلبها. رحلة Chromium تتحقق من الموافقة والحفظ بعد إعادة الفتح وتحديث القراءة والمسح من تبويب حقيقي آخر، وبقاء سائر مفاتيح التخزين، وفشل الحفظ، والعرض 320–1440، وبقاء الحظر والنسخ والمصدر. يُسجل عدد الاختبارات ونتيجة النشر الفعلي بعد اكتمالها.

نتيجة التحقق المحلي: **221 اختبار وحدة وحماية ناجحًا**، ورحلة Chromium الكاملة بلا أخطاء تشغيل، ومحاكي Firestore ناجح، وبناء وفحص الأصول العامة ناجحان. شملت الرحلة الحفظ بعد إعادة التحميل، والتحديث التلقائي للقيم عند الاختيار، والمسح من تبويب آخر، وسلامة مفاتيح الجلسة والمفضلة، وفشل التخزين، وفحص الأذونات، ومقاسات 320–1440. راجعت صورة فعلية للوحة الخصوصية على 390 بكسل؛ لم تُستخدم بيانات عضو إنتاجية أو تتغير قواعد المصدر.
