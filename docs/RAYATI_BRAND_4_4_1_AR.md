# تطبيق رعايتي — الإصدار 4.4.1

19 أكتوبر 2026. اعتماد الاسم داخل التطبيق نفسه بعد الحملة. تحديث الترويسة والتذييل والترحيب وبطاقة العضو وعنوان الإدارة وعنوان المتصفح وبيانات الدليل وPWA واسم تثبيت iOS. تبقى هوية PWA `./` كما هي لحماية الانتقال من النسخة القديمة، وتبقى مفاتيح الجلسات والبيانات والحقوق والتعاقدات كما هي.

الشعار الطبي الجديد: `img/rayati-app.png`، قلب ونبض بهوية WE وشارة النقابة، مع شفافية خارج البلاطة. صورة المشاركة `img/rayati-share.png` بقياس 1200×630. أُضيف Open Graph وTwitter Card باسم «تطبيق رعايتي» وصورة عامة بلا معلومات أعضاء. ملف `scripts/render-share-image.mjs` يعيد بناء بطاقة المشاركة باستخدام Playwright وCairo والأصل المرفق.

تم جلب ودمج تعديلات المالك في README وindex وmanifest، ثم استبدال التغيير الجزئي بالتغيير الكامل دون إعادة كتابة تاريخ Git. سبب فشل GitHub المثبت: assertion لاسم manifest كان يتوقع «نبض النقابة» بينما القيمة أصبحت «تطبيق رعايتي». سجل Vercel لذلك الالتزام نفسه كان success.

التحقق المحلي: 91 اختبار وحدة ناجح، وبناء وفحص الملفات العامة، واختبار المتصفح لمسارات العضو والإدارة والتثبيت والتحديث ودقات 320 و390 و768 و1440. تغيرت توقعات الاختبارات الموجودة لتطابق الاسم والأيقونة والإصدار الجديد. تحديث معرف Service Worker وروابط الأصول يتيح تنزيل النسخة الجديدة.

رابط الإنتاج: https://medical-nekaba.vercel.app/ . صورة المشاركة تعتمد هذا الأصل الحالي. عنوان مقترح في حال رغبة المالك بتغيير عنوان الرابط نفسه: `rayati-we.vercel.app`، ولم يُحجز أو يُربط بعد. جلسة Vercel CLI غير مسجلة، لذلك لا توجد صلاحية لإضافة النطاق من هنا. إضافة نطاق فعلي تحتاج إعداده في Vercel والتأكد من إدراجه في CORS الخاص بـMedical ونشر السماح عند الحاجة، ثم اختبار الصحة وOPTIONS وتسجيل الدخول، قبل الإعلان عنه. يبقى الرابط السابق فعالًا.

لا تتغير إعدادات Firebase أو MyNekaba بهذا الإصدار؛ بيانات عنوان الدليل في ملفات المصدر ليست سجلات عضوية. حالة الإنتاج النهائية تُثبت بعد push ومطابقة الأصول المنشورة.
