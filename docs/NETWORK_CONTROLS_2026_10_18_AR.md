# تحديث البطاقة وإدارة الشبكة — 18 أكتوبر 2026

## ما تغير

بطاقة نقابية جديدة بهوية نبض النقابة وشعار النقابة وحقول شخصية مرتبة؛ لا تُحفظ بياناتها محليًا. لوحة الإدارة تعرض الأعداد الفعلية، وتصفية حسب نوع السجل وحالته، وإجراءات مستقلة للإخفاء والإيقاف والاستئناف. الصف يمثل مقرًا؛ للطبيب متعدد المقار خيار تطبيق الحالة على جميع مقاره الحالية في معاملة واحدة مع منع تعارض النسخ.

الدليل يصل للعضو بعد ترشيح الجهات المخفية على الخادم، بما فيه إحصاء تقييماتها. الرابط القديم لا يعيد الجهة المخفية ولا يتيح إنشاء تقييم لها. تبقى تقييمات الكاتب التاريخية في حسابه. الجهة الموقوفة تبقى ظاهرة بشارة «موقوف مؤقتًا»؛ الاستعلام والاتصال وتقييم زيارة سابقة لا يعنيان إتاحة خدمتها الآن. يستمر فصل هوية الطبيب عن مقاره وتعاقداته.

إخفاء المستشفى يخفي مقار أطبائها المرتبطة بها، وإيقافها يوسم المقار نفسها بالتوقف؛ لا تتأثر علاقات الطبيب مع مستشفى أخرى. هذا اشتقاق للعرض لا حذف للعلاقات. القرار الجماعي يخص المقار الموجودة وقت الحفظ؛ لا يشمل مقرًا يضاف لاحقًا تلقائيًا.

تبويب مستقل لمراكز الدقهلية الستة عشر يعرض شبكتها المرئية وأعدادها الفعلية. الأسنان ضمن تبويبات الخدمات ويجمع الأطباء والمراكز المختصة دون اشتراط كون الجهة عيادة. مقدمة الرئيسية أصغر، مع استمرار أدوات البحث والمفضلة والطوارئ.

الرسم غير المحدد للطبيب فريق طبي من طبيب وطبيبة، بدل عرض ذكر لجميع الأسماء؛ الاختيار الصريح للطبيبة محفوظ ويقدم عند العرض. لا نخمن جنس الأشخاص من الاسم. تعالج قيم الحقول النصية المفقودة مثل null عند حدود العرض، وتُفحص تواريخ الدخول قبل تنسيقها. لا تُغير ملاحظات المستخدمين أو بيانات المصدر.

حُذفت عبارة الاتصال لمعرفة المواعيد من بطاقات الصيدليات عندما لا توجد مواعيد. استبدلت بطاقة مسؤول الرعاية في الطوارئ بخطّي الرعاية اللذين حددهما المالك: موظفون 16133، أسر ومعاشات 19104. لا يوجد ادعاء باختبار مكالمة أو تشغيل 24 ساعة.

## التشغيل والنشر

تحسينات العرض تنشر عبر GitHub Pages. تفعيل حفظ الإخفاء والإيقاف وحفظ اختيار الرسم الصريح يحتاج نشر Firebase؛ الواجهة تتحقق من `directory-state-v1` وتمنع الحفظ إذا كانت الخدمة قديمة، ولا تعلن نجاحًا وهميًا. تغييرات حالة الجهات بعد نشر هذا الإصدار تحفظ فورًا دون نشر كود جديد.

من Cloud Shell داخل النسخة التي تحتوي الإعدادات المحفوظة:

```bash
cd ~/cloudshell_open/Medical && git pull --ff-only && bash scripts/deploy-medical.sh --existing-config
```

بعد نجاح النشر يمكن التحقق العام دون بيانات دخول:

```bash
node scripts/check-live.mjs --require-staff
```

الفحص الإلزامي يتضمن `directory-state-v1` و`provider-illustrations`. النجاح التاريخي لإصدار سابق أو نجاح خطوة readiness في Actions لا يثبت نشر Firebase الحالي. حساب Google غير متصل ببيئة المساعد؛ التهيئة الآلية الخارجية ما زالت غير مفعلة. لم يُعدل MyNekaba.

## التحقق

اختبارات وحدة لحجب الجهات عن العضو مع بقاء وصول المدير، ورفض تقييم جهة مخفية، ومنع التعارض، واستقلال مقار الطبيب، والتعليق المؤقت، والاستعادة. محاكي Firestore يختبر معاملة جميع المقار ورفض الحفظ الجزئي عند تغير إصدار أحدها. المتصفح يختبر أزرار الإدارة وانعكاس القرار على دخول عضو مستقل، والأسنان بالمراكز، والمراكز الستة عشر، وأرقام الرعاية، والصيدليات، والرسوم والنصوص والبطاقة، مع اختبارات الدخول والتقييمات السابقة وقياسات الهاتف والحاسب.
