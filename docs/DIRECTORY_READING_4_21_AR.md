# القراءة المريحة والبحث الموجّه — 4.21.0

23 أكتوبر 2026. استكمال N-D05/N-D06/N-D07 وD07/C03 في [الاتفاقية](../APP_AGREEMENT_AR.md)، ضمن قرار المالك إبقاء الجديد للإدارة فقط.

## موضع التجربة

الإدارة ← معمل التطوير ← تجربة الدليل المترابطة ← فتح المعاينة.

«خيارات القراءة والعرض» أعلى معاينة الدليل: حجم عادي/كبير/أكبر، بطاقات مختصرة، تباين أوضح، وتقليل حركة، مع استعادة العرض العادي. هذه الخيارات لا تغير إعدادات صفحات الأعضاء أو بقية المعمل. لا تستنتج حاجة شخص من عمره أو حالته، ولا تعتمد على بيانات عضوية.

تبقى الخيارات في ذاكرة هوية المدير الحالية أثناء الانتقال وفتح الجهات والرجوع والتقدم والتخصصات. لا تستخدم localStorage أو cookies أو Firestore لهذا الغرض؛ تزول بالخروج من الهوية أو إعادة تحميل الصفحة. لا تعد إعدادات دائمة عبر الأجهزة. الوضع عالي التباين يستخدم سطحًا فاتحًا مستقلًا داخل المعاينة حتى مع وضع التطبيق الداكن. تقليل حركة نظام التشغيل محترم أيضًا دون الحاجة لتفعيل الخيار.

الاختصار يحذف سطر العنوان التفصيلي من البطاقة فقط ويقلل المسافات؛ المدينة والاسم والتخصص والشبكات والمقار وحالة الخدمة والتقييم تبقى ظاهرة. فتح الجهة يبقي كامل العنوان وأرقام الهاتف المصنفة والخرائط والتقييمات المنشورة. لا يخفي وضع الاختصار إيقاف الخدمة أو المقار الأخرى.

## البحث الصريح

تظهر حتى ثلاثة اقتراحات «تخصص في منطقة» من الدليل الذي سمح الخادم بقراءته بالفعل، ضمن الشبكة والقسم والمركز والتخصص الحاليين. يحسب العدد جهات فريدة وفق معرّفات التجميع القائمة؛ المقار المتعددة لا تضاعفه، والاسم وحده لا يدمج طبيبين. الاقتراح ليس ترشيحًا طبيًا ولا وعدًا بحجز أو أهلية مالية؛ قد توجد جهة موقوفة ويظل وضعها ظاهرًا.

تتجدد الاقتراحات محليًا بعد 180 مللي ثانية من الكتابة، مع انتظار اكتمال تركيب النص. لا ترسل ضغطات المفاتيح أو نص البحث إلى الخادم أو محرك خارجي. عند عدم تطابق تخصص/مدينة لا تُختلق نتيجة؛ يمكن إرسال البحث الاسمي المعتاد. التصحيح القريب موسوم ويحتاج اختيارًا، ولا يبدل نص المستخدم تلقائيًا.

عند اختيار اقتراح يصبح التخصص والمركز مرشحين واضحين، ويفرغ نص البحث الخاص بالاقتراح لتجنب تكرار القيد. القسم والشبكة المختاران يبقيان كما هما. مرشحات القسم والمستفيدين والبحث والمركز والتخصص كلها قابلة للإزالة منفردة، مع مسح شامل. تغيير القسم ينظف المرشحات السابقة وفق السلوك القائم. لا توسيع خفي للشبكة أو إزالة قيد دون فعل المستخدم.

## التنقل والإتاحة

- بيان حي لعدد النتائج والمرشحات، وزر «انتقل إلى النتائج»، وتركيز واضح بعد البحث أو التصفية.
- اسم وصول لزر تفاصيل كل جهة يذكر اسمها؛ لا تعتمد الدلالة على الأيقونة وحدها.
- فتح جهة يركز عنوانها، والرجوع يعيد زرها والبحث والتمرير. تغيير خيارات القراءة يعيد التركيز إلى نفس أداة الاختيار ويحفظ التمرير.
- تبويبات التفاصيل تستخدم أسهم RTL وHome/End مع عنصر محدد واحد ضمن ترتيب Tab. اختيار المقر أو الشبكة يعيد التركيز إلى اختياره.
- الحد الأدنى لأدوات اللمس الجديدة 44 بكسل، والتفاف النص والأزرار على الشاشات الصغيرة. الحجم الأكبر يستخدم عمود بطاقات واحد، والاتصال/الخريطة ضمن تدفق الموبايل لتجنب تغطية التفاصيل.

الفحوص البرمجية للتركيز والتسميات والتباين المقصود والالتفاف لا تعادل تجربة NVDA/VoiceOver/TalkBack الفعلية أو شهادة توافق شاملة. لم تُضف قراءة صوتية؛ ذلك يحتاج تقييم النطق والخصوصية وفائدة الاستخدام أولًا.

## الصلاحيات والتوافق

المراجعة الجديدة **`p1-directory-20261023-2`** في الخادم والعميل والمعمل. أي اعتماد سابق للتصميم يعود «بانتظار المراجعة» ويحتفظ بتاريخه؛ لا ينتقل اعتماد سابق لتصميم مختلف. يظل الإيقاف محفوظًا. لا يسمح الاختلاف بمراجعة عينة قديمة، وتبقى العينات الأخرى متاحة.

لا مسار API جديد للبحث أو حفظ الخيارات. يستخدم المسار القائم `GET /v1/admin/lab/preview/directory_experience`، وتفحص حالة المعاينة فقط كل 20 ثانية أثناء ظهورها. التحقق الخادمي حي، وحجب الزيارة/العضو والإيقاف وفشل الاتصال والرد المتأخر كما في الإصدار السابق. هذه الفحوص لا تجدد جلسة خمول المدير. لا كتابة إلى الدليل أو MyNekaba أو تعليقات الأعضاء أو إشعاراتهم، ولا تحديث للعضو أو خبر من تجربة المعمل.

قدرة الصحة **`development-directory-comfort-v1`** تميز نشر الخدمة الجديدة؛ لا تعني نشر جمهور جديد. تحتاج الواجهة 4.21.1 وخدمة متوافقة. من Cloud Shell المخول:

```bash
cd ~/cloudshell_open/Medical && git pull --ff-only origin main && bash scripts/deploy-medical.sh --existing-config
```

ثم فحص عام دون دخول خاص:

```bash
NODE_USE_ENV_PROXY=1 node scripts/check-live.mjs --rayati --require-directory-comfort --require-admin-inbox
```

لم تتصل هوية Google ببيئة المساعد، ولا يكفي نجاح Vercel أو مهمة GitHub التي تتجاوز نشر Firebase. يذكر تقرير التسليم حالة كل نشر فعليًا.

الرجوع بإيقاف «تجربة الدليل المترابطة» من قرار العينة في المعمل؛ لا حذف للتاريخ أو الدليل، وتبقى تجربة الأعضاء. لإرجاع الكود يلزم زوج متوافق من الواجهة والخدمة.

## التحقق

البيانات المستخدمة في اختبارات الهوية والتقييمات مصطنعة؛ لا دخول إنتاج خاص أو تعديل جهة إنتاج من الاختبارات. اختبارات النموذج تتحقق من حصر الاقتراحات في البيانات والشبكات والأقسام القائمة، وتوحيد عدد مقار الجهة، والتصحيح القريب، والحد الأقصى، وعدم تغيير المصدر. اختبار خدمة يحجز اعتماد المراجعة القديمة ولا يغير دليل العضو أو بياناته. رحلة المتصفح تغطي الخيارات والبحث والمرشحات والتركيز والرجوع وتبويبات لوحة المفاتيح ومقاسات 320–1440 وتقليل الحركة، إضافة إلى رحلات الحماية القائمة. تسجل النتائج الفعلية بعد انتهاء الفحوص.

التحقق المحلي لهذه الحزمة: **201 اختبار وحدة وحماية ناجحًا**، ورحلة المتصفح الكاملة دون أخطاء JavaScript، ومحاكي Firestore ناجح، وبناء الأصول وفحصها ناجحان. شمل المتصفح الحجم الأكبر مع التباين والاختصار وتقليل الحركة على 320 و390 و768 و1440 بكسل دون تجاوز أفقي، واختيار الاقتراح وإظهار مرشحيه، واستعادة الإعدادات والتركيز والتمرير عند الرجوع، وتبويبات التفاصيل بلوحة المفاتيح. لا تعادل الاختبارات استخدام قارئ شاشة بشري أو دخول حساب إنتاج خاص، ولا تثبت نشر الخلفية الجديدة.
