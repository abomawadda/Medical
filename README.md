# منظومة الدليل الطبي الموحد — الشركة المصرية للاتصالات WE (الدقهلية)
### إعداد وتنفيذ: الأستاذ / محمود العراقي
### برعاية: اللجنة النقابية للعاملين بالمصرية للاتصالات بمحافظة الدقهلية

---

## 🌟 نظرة عامة على الإصدار المطور (v2.1)

تمت إعادة هيكلة وتطوير المنظومة بالكامل لتكون **منظومة رعاية صحية رقمية شاملة** تحاكي أحدث تطبيقات الهواتف الذكية المعتمدة عالمياً (Native Mobile App Experience)، مع تخصيص واجهة المستخدم واستقلالية لوحة الإدارة، وتنظيم الخدمات الطبية لخدمة الزملاء العاملين بالشركة المصرية للاتصالات وأسرهم بمحافظة الدقهلية.

---

## 🚀 أبرز التحديثات والتعديلات المنفذة:

### 1. توزيع الشعارات الرسمي والمتوازن:
- **شعار الشركة المصرية للاتصالات WE الرسمي:** في أعلى اليمين.
- **شعار اللجنة النقابية للعاملين بالاتصالات بالدقهلية:** في أعلى اليسار.
- **في المنتصف:** اسم المنظومة مع سطر التوثيق الرسمي:
  `إعداد وتنفيذ: الأستاذ / محمود العراقي`

### 2. واجهة رئيسية عصرية (Mobile Hub Dashboard):
- **عدم تكديس الأطباء في الواجهة الرئيسية:** كما طُلب تماماً، الواجهة الرئيسية أصبحت منصة تنقل ذكية ومركزاً رئيسياً (Hub) يحتوي على:
  - شريط بحث ذكي وبارز مع مقترحات فورية.
  - شبكة الأقسام الطبية الـ 12 بأيقونات وتدرجات لونية جذابة تشبه تطبيقات Talabat و Vezeeta.
  - صروح الدقهلية الطبية الشريكة (الحكمة، السلاب، الخير).
  - بانر الطوارئ وطلب الموافقات الطبية السريعة.
- **ظهور الأطباء بناءً على البحث أو اختيار التخصص حصراً:** عند الضغط على أي تخصص طبي أو كتابة أي حرف في البحث، ينتقل التطبيق فوراً إلى شاشة استعراض الأطباء المطابقين مع زر عودة سلس للرئيسية.

### 3. حل مشكلة عرض الأطباء عند الضغط على التخصص:
- تم ربط كافة بطاقات التخصصات وشبكة الأيقونات بمحرك التصفية الفوري، بحيث يظهر فوراً أطباء واستشاريو التخصص المختار مع توضيح اسم التخصص وعدد الأطباء المتاحين في شريط التصفية العلوي.

### 4. تغطية شاملة لكافة الخدمات الطبية التخصصية:
لم يعد الدليل مقتصراً على المستشفيات فقط، بل تم تدشين قسم متكامل للخدمات الطبية بالدقهلية يضم:
- **معامل التحاليل الطبية:** (المختبر، البرج، ألفا لاب، كايرو لاب) مع أرقام الخط الساخن وإمكانية طلب سحب العينات منزلياً.
- **مراكز الأشعة والتصوير الطبي:** (كايرو سكان، ألفا سكان، مركز مصر للأشعة) مع أحدث أجهزة الرنين المغناطيسي والأشعة المقطعية.
- **الصيدليات الكبرى وخدمة التوصيل:** (صيدلية الإسعاف 24س، صيدليات الطرشوبي، صيدليات سالي، صيدليات العزبي) مع أرقام الدليفري وأدوية الطوارئ.
- **مراكز وعيادات طب الأسنان:** (مركز دينتال كير وعيادات الأسنان المعتمدة).
- **مراكز العيون والبصريات:** (مركز أوبتكس ون، واستشاريو العيون وجراحات الليزك).
- **مراكز الغسيل الكلوي:** (وحدة الكلى بمستشفى الخير ومراكز الغسيل الكلوي).
- **مراكز قسطرة القلب طوارئ 24 ساعة:** (مركز قسطرة القلب بمستشفى الخير بالمنصورة).
- **مراكز العلاج الطبيعي والتأهيل:** (مركز فرست للعلاج الطبيعي والتأهيل الحركي).
- **الرعاية والتمريض المنزلي (Home Care):** خدمات التمريض المنزلي لكبار السن وما بعد العمليات الجراحية.

### 5. إمكانية إضافة الجديد وحفظه فورياً:
تم توفير مسارين مستقلين لإضافة الجديد:
- **من خلال لوحة الإدارة (Admin Panel):** نموذج تفاعلي كامل لإدراج طبيب أو معمل أو صيدلية أو مركز طبي بجميع البيانات (الاسم، التصنيف، التخصص، مقار العمل، التليفونات، العنوان، وأيام ومواعيد العمل)، ويحفظ السجل مباشرة في قاعدة البيانات المحلية.
- **من خلال المستخدمين (Crowdsourcing):** زر عائم (+) يتيح لأي زميل بالشركة اقتراح وترشيح طبيب أو جهة جديدة، لتصل فوراً لصندوق مقترحات لوحة الإدارة للمراجعة والاعتماد بنقرة واحدة.

### 6. الفصل التام بين واجهة المستخدم ولوحة الإدارة:
- **المستخدم العادي:** يرى واجهة سهلة وبسيطة للتصفح والبحث والاتصال والخرائط والمفضلة والطوارئ دون أي تعقيد.
- **لوحة الإدارة:** محمية برمز دخول سري (الافتراضي: `we2026`)، وتتيح للمسؤولين فقط:
  - إدراج جهات وأطباء جدد.
  - فحص مدقق جودة البيانات (السجلات التي تنقصها هواتف أو تفاصيل مواعيد).
  - كاشف التكرار الذكي.
  - استعراض مقترحات الزملاء واعتمادها.
  - تصدير البيانات إلى Excel / CSV أو نسخة احتياطية JSON.

### 7. أفكار ومقترحات خارج الصندوق:
- **زر طوارئ SOS عائم نابض:** يتيح بنقرة واحدة الوصول للإسعاف (123) أو قسطرة طوارئ 24س أو نجدة الدقهلية.
- **رمز استجابة سريعة (QR Code):** لكل طبيب وجهة لمسحه بكاميرا الموبايل وحفظ بيانات التواصل فوراً.
- **نموذج طلب موافقة طبية فوري:** يجهز رسالة بريد إلكتروني رسمية ببيانات موظف WE ورقم التأمين موجهة لإدارة الموافقات بـ `Elkhier.hospital@gmail.com`.
- **بطاقة طبيب رقمية متكاملة:** تضم كافة أماكن عمله مع إمكانية التبديل بين الداخلي والخارجي والاتصال بضغطة زر.
